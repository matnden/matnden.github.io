# عن الكتاب

الكتاب: بَدْءِ الأَمَالِي
المؤلف: علي بن عثمان الفرغاني الحنفي (المتوفى: ٥٧٥ هـ)
الموضوع: منظومة في أصول الدين والعقيدة، ستة وثمانون بيتاً في التوحيد وصفات الله والنبوات وأصول الفقه.
من شروحها: ضوء اللّآلي، لابن كاتب الينكجرية (ت ١١٢١ هـ).
النص: المكتبة الشاملة، رقم الكتاب ٥٦٩.

أبيات المنظومة مرقمة، وصدر كل بيت وعجزه مفصولين بفراغ واسع.

# المتن

بسم الله الرحمن الرحيم

1 يقولُ العبدُ في (بَدْءِ الأَمَالِي)|dictations // لتوحيدٍ|monotheism بِنَظْمٍ|verse كاللآلي|like_pearls
2 إلهُ|deity الخَلْقِ مَولانا قديمٌ|pre-existent // وموصوفٌ بأوصافِ الكمالِ|perfection
3 هُوَ الحَيُّ المُدَبِّرُ|disposer كُلَّ أمرٍ // هُوَ الحَقُّ المُقَدِّرُ|ordainer ذو الجلالِ|majesty
4 مُرِيْدُ الخيرِ والشرِّ القبيحِ|vile // ولكنْ ليسَ يرضى بِالمُحَالِ|the_impossible
5 صفاتُ اللهِ ليستْ عينَ|selfsame ذاتٍ|essence // ولا غَيْراً سواهُ ذا انفصالِ|separation
6 صفاتُ الذاتِ والأفعالِ|acts طُرّاً|wholly // قديماتٌ مَصوناتُ|preserved الزوالِ|extinction
7 نُسَمِّيْ اللهَ شيئاً لا كالاشيا // وَذَاناً عَنْ جهاتِ|directions السِّتِّ خالي
8 وليسَ الإسمُ غيراً لِلْمُسَمَّى|the_named // لدى أهلِ البصيرةِ|insight خيرِ آلِ
9 وما إِنْ جَوْهَرٌ|substance ربي وجسمٌ // ولا كُلٌّ وبعضٌ ذو اشتِمالِ|encompassing
10 وفي الأذهانِ حَقٌّ كونُ جزءٍ // بلا وصفِ التَّجَزِّيْ|division يا ابْنَ خالي
11 وما القرآنُ مخلوقاً تعالى // كلامُ الرَّبِّ عَنْ جنسِ|kind المقالِ|discourse
12 وَرَبُّ العرشِ|Throne فوقَ العرشِ لكنْ // بلا وصفِ التمكنِ واتصالِ|connection
13 وما التشبيهُ|likeness للرحمنِ وَجْهاً|manner // فَصُنْ عَنْ ذَاكَ أصنافَ الأهالي|peoples
14 ولا يمضي على الدَّيَّانِ|judge وقتٌ // وأحوالٌ وأزمانٌ بِحَالِ
15 ومستغنٍ|self-sufficient إلهي عن نساءٍ // وأولادٍ إناثٍ أو رجالِ
16 كذا عن كُلِّ ذي عونٍ ونصرٍ // تَفَرَّدَ ذو الجلالِ وذو المعالي|excellences
17 يُمِيْتُ الخلقَ طُرّاً|wholly ثم يُحيي // فيَجزيهمْ على وَفْقِ|accordance الخِصَالِ|traits
18 لأهلِ الخيرِ جناتٌ وَنُعْمَى|blessings // وللكفارِ إدراكُ النَّكَالِ|punishment
19 ولا يَفنى الجحيمُ|hellfire ولا الجِنَانُ|gardens // ولا أهلوهُما أهلُ انتقالِ|passage
20 يراهُ المؤمنونَ بغيرِ كيفٍ|modality // وإدراكٍ|perception وضربٍ مِنْ مِثَالِ|likeness
21 فينسَونَ النعيمَ إذا رأوهُ // فيا خُسرانَ أهلِ الإعتزالِ|Mu'tazilites
22 وما إِنْ فِعْلُ أَصْلَحْ ذو افتراضٍ|supposition // على الهادي المُقَدَّسِ ذي التعالي
23 وفرضٌ|obligation لازمٌ|binding تصديقُ رسلٍ // وأملاكٍ|angels كرامٍ بالتوالي|successively
24 وَخَتْمُ الرسلِ بالصدرِ المُعَلَّى|exalted // نبيٌّ هاشميٌّ|Hashimite ذو جمالِ
25 إمامُ الأنبياءِ بلا اختلافٍ // وتاجُ|crown الأصفياءِ|the_chosen بلا اختلالِ|defect
26 وَبَاقٍ شَرْعُهُ|his_law في كُلِّ وقتٍ // إلى يومِ القيامةِ وارتحالِ
27 وَحَقٌّ أمرُ معراجٍ|Ascension وصدقٌ // ففيه نَصُّ|text أخبارٍ عوالِ
28 ومرجوٌّ شفاعةُ|intercession أهلِ خيرٍ // لأصحابِ الكبائرِ|major_sins كالجبالِ
29 وَإِنَّ الأنبياءَ لفي أمانٍ|security // عَنِ العصيانِ عَمْداً|deliberately وانعزالِ|withdrawal
30 وما كانتْ نَبِيّاً قَطُّ أنثى // ولا عَبْدٌ وشخصٌ ذو افتِعالِ
31 وذو القَرنينِ لَمْ يُعْرَفْ نبياً // كذا لقمانُ فاحذرْ|beware عَنْ جِدَالِ|disputation
32 وعيسى سوفَ يأتيْ ثُمَّ ينويْ // لدجالٍ|Antichrist شقيٍّ|wretched ذِيْ خَبَالِ|ruin
33 كراماتُ|miracles الوليِّ|saint بدارِ دنيا // لها كَوْنٌ فَهُمْ أهلُ النوالِ
34 وَلَمْ يَفْضُلْ وليٌّ قَطُّ دهراً // نبياً أو رسولاً في انتحالِ|claiming
35 وَلِلصِّدِّيْقِ|Abu_Bakr رُجحانٌ|preponderance جليٌّ // على الأصحابِ مِنْ غيرِ احتمالِ
36 وللفاروقِ|Umar رجحانٌ وفضلٌ // على عثمانَ ذي النورينِ عالِ
37 وذو النورينِ|the_Two_Lights حقاً كانَ خيراً // مِنَ الكَرَّارِ|Ali في صَفِّ القتالِ
38 وللكرارِ فضلٌ بعدَ هذا // على الأغيارِ طُرّاً لا تُبَالِ
39 وللصِّدِّيقةِ|Aisha الرُّجحانُ فاعلمْ // على الزهراءِ|Fatimah في بعضِ الخِلَالِ
40 وَلَمْ يَلْعَنْ يزيداً|Yazid بعدَ موتٍ // سوى المِكثارِ في الإغراءِ غَالِ
41 وإيمانُ المُقَلِّدِ|imitator ذو اعتبارٍ // بأنواعِ الدلائلِ|proofs كَالنِّصَالِ|like_blades
42 وما عذرٌ لذي عقلٍ بجهلٍ // بِخَلَّاقِ الأسافلِ|lower والأعالي|higher
43 وما إيمانُ شخصٍ حَالَ يَأْسٍ|despair // بمقبولٍ لِفَقْدِ الإمتثالِ|compliance
44 وما أفعالُ خيرٍ في حسابٍ // مِنَ الإيمانِ مَفْرُوْضَ الوِصَالِ
45 ولا يُقْضَى بكفرٍ وارتدادٍ|apostasy // بقهرٍ أو بقتلٍ واختزالِ
46 وَمَنْ يَنْوِيْ ارتداداً بعدَ دهرٍ // يَصِرْ عَنْ دينِ حَقٍّ ذا انسلالِ
47 ولفظُ|utterance الكفرِ مِنْ غيرِ اعتقادٍ // بطوعٍ رَدُّ دِيْنٍ باغتفالِ|negligence
48 ولا يُحكمْ بكفرٍ حَالَ سُكْرٍ|intoxication // بما يَهذي ويَلغو بارتجالِ|extempore
49 وما المعدومُ|nonexistent مَرئياً وشيئاً // لفقهٍ لاحَ في يُمْنِ الهِلَالِ
50 وَغَيْرَانُ المُكَوِّنِ لا كشيءٍ // مَعَ التكوينِ خُذْهُ لاكتحالِ
51 وَإِنَّ السُّحْتَ|unlawful_gain رِزْقٌ مثلَ حِلٍّ|lawful // وَإِنْ يَكْرَهْ مَقالي كُلُّ قالي
52 وفي الأجداثِ|graves عَنْ توحيدِ ربي // سيُبلى كُلُّ شخصٍ بالسؤالِ
53 وَلِلْكُفَّارِ وَالفُسَّاقِ يُقضى // عذابُ القبرِ مِنْ سوءِ الفِعَالِ
54 دخولُ الناسِ في الجناتِ فضلٌ // مِنَ الرحمنِ يا أهلَ الأمالي
55 حسابُ النَّاسِ بعدَ البعثِ|Resurrection حَقٌّ // فكونوا بالتحرُّزِ عَنْ وَبَالِ|calamity
56 وتُعطى الكُتْبُ|records بعضاً نحوَ يُمنى // وبعضاً نحوَ ظَهْرٍ وَالشِّمَالِ
57 وَحَقٌّ وزنُ أعمالٍ وَجَرْيٌ // على متنِ الصراطِ بلا اهْتِبَالِ|hastening
58 وَمَرْجُوٌّ شفاعةُ أهلِ خيرٍ // لأصحابِ الكبائرِ كالجبالِ
59 وَلِلدَّعَوَاتِ تأثيرٌ بليغٌ|potent // وَقَدْ ينفيهِ أصحابُ الضلالِ
60 ودنيانا حديثٌ وَالهُيولَى|prime_matter // عديمُ|devoid الكونِ فاسمعْ باختزالِ
61 وللجناتِ والنيرانِ كونٌ|existence // عليها مَرَّ أحوالٌ خَوَالِ
62 وذو الإيمانِ لا يبقى مُقيماً // بسوءِ الذَّنْبِ في دارِ اشتعالِ|blazing
63 لقدْ ألبستُ للتوحيدِ نَظْماً|system // بديعَ|wondrous الشكلِ كَالسِّحْرِ|magic الحَلَالِ|lawful
64 يُسَلِّيْ القلبَ كالبُشرى بِرَوْحٍ|comfort // وَيُحْيِيٍ الرُّوْحَ كالماءِ الزُّلَالِ|pure_water
65 فخُوضوا فيهِ حفظاً واعتقاداً // تنالوا جِنْسَ أصنافِ المَنَالِ|attainment
66 وكونوا عَوْنَ هذا العبدِ دَهْراً // بِذِكْرِ الخيرِ في حالِ ابتهالِ|supplication
67 لعلَّ اللهَ يعفوهُ بِفَضْلٍ // ويعطيهِ السعادةَ في المَآلِ|outcome
68 وَإِنِّيْ الحَقَّ أدعو كُلَّ وقتٍ // لِمَنْ بالخيرِ يوماً قَدْ دَعَا لِيْ
